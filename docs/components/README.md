# Components

Specifications of the PowerUI components, each with a reference image. Colors refer to the
[tokens](../foundations/tokens.md) and sizes to the [layout](../foundations/layout.md).

| Component | Page |
|---|---|
| Card | [card.md](card.md) |
| Buttons (outline, secondary, soft, primary, destructive, rail) | [buttons.md](buttons.md) |
| Segmented group | [segmented.md](segmented.md) |
| Switch, slider and progress bar | [controls.md](controls.md) |
| Badge, icon tile and select | [badges-tiles-select.md](badges-tiles-select.md) |
| List row | [list-row.md](list-row.md) |
| Menu card and empty state | [menu-card-and-empty-state.md](menu-card-and-empty-state.md) |
| Dialog | [dialog.md](dialog.md) |

The status-bar icons (camera, filament, Wi-Fi) are 18 px: green means active and gray with a diagonal slash means inactive.

The images are rendered by [`tools/render_reference.py`](../../tools/render_reference.py) with Lucide icons only.
